# Overview

This repository documents my journey of learning Git and GitHub while building small programming projects and practicing version control.

Instead of using Git only for uploads, I learned how to manage source code professionally by creating meaningful commits, organizing repositories, and tracking project history.

The projects included here cover programming fundamentals while demonstrating consistent Git usage throughout development.
